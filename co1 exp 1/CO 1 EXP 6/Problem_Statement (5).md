# Experiment 06 – Design UML Diagrams for an Online Food Delivery System

## Aim

To analyze the requirements of an Online Food Delivery System and design the UML diagrams, namely the Class Diagram, Use Case Diagram, and Activity Diagram, using the Umbrello tool.

---

## Problem Statement

An online food delivery platform enables customers to browse restaurants, view menus, place food orders, make online payments, and track delivery status. Restaurants use the system to manage their menus and update order status, while delivery agents are responsible for accepting delivery requests and updating delivery progress.

Using the **Umbrello** tool, design the following UML diagrams for the Online Food Delivery System:

- Class Diagram
- Use Case Diagram
- Activity Diagram

The Class Diagram should represent the relevant classes, their attributes, methods, and relationships. The Use Case Diagram should illustrate the interactions between actors and the system. The Activity Diagram should describe the workflow from placing an order to successful delivery.

---

## Objectives

- Understand the fundamentals of UML modeling.
- Identify the key actors and system functionalities.
- Design a Class Diagram representing system structure.
- Create a Use Case Diagram to represent user interactions.
- Develop an Activity Diagram to model the workflow of the system.

---

## Requirements

Design the following UML diagrams:

### 1. Class Diagram

Include classes such as:

- Customer
- Restaurant
- Menu
- Food Item
- Order
- Payment
- Delivery Agent
- Delivery
- Admin

Include appropriate:

- Attributes
- Methods
- Relationships (Association, Aggregation, Composition, Inheritance)

---

### 2. Use Case Diagram

Actors:

- Customer
- Restaurant
- Delivery Agent
- Admin

Sample Use Cases:

- Register/Login
- Browse Restaurants
- View Menu
- Place Order
- Make Payment
- Track Order
- Accept Delivery Request
- Update Delivery Status
- Manage Menu
- Manage Users

---

### 3. Activity Diagram

Workflow:

1. Customer Login
2. Browse Restaurants
3. Select Food Items
4. Place Order
5. Make Payment
6. Restaurant Accepts Order
7. Food Preparation
8. Delivery Agent Accepts Delivery
9. Deliver Order
10. Customer Receives Order
11. Order Completed

---

## Tools Required

- Umbrello UML Modeller

---

## Expected Outcome

An Online Food Delivery System modeled using UML diagrams, including a Class Diagram, Use Case Diagram, and Activity Diagram, accurately representing the system's structure, functionality, and workflow.
